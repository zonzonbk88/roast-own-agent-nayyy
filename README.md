> Our agent re-reads the brief, re-verifies the contract, re-runs the dry-run — then hits a rate limit and forgets what it was minting.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the one-line roast to `/output/entry.txt` (133 characters, valid UTF-8, one line).
